# Lebesgue Integral

The *lebesgue integral* is a generalization of the Riemann integral.

<i>

**definition [d]** (*Lebesgue Integral*) 
The *Lebesgue integral* is defined by
$$
\int_X f \, d \mathcal{M} = \sup \left\{ \int_X s \, d \mathcal{M} \ \middle|\ s : X \to \mathbb{R} \ \text{ and } 0 \le s \le f \right\}.
$$

where:

- $f: X \rightarrow [0,\infty]$ is a non-negative measurable function
- $\mathcal{M}$ is the measure
- $X$ is a set of the measure space
- $s$ is a simple function
