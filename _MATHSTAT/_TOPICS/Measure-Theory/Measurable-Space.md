# Measurable Space

The following is the definition of the *measurable space*–not to be confused with the "measure space."

<i>

**definition [d]** (*Measurable Space*) 
A *measurable space* is the space $(X,\mathcal{E})$ if

- $\mathcal{E} \subset P(X)$

where:

- $\mathcal{E}$ is $\sigma$-algebra
- $X$ is a set
- $P(X)$ is the family of all subsets

</i>
