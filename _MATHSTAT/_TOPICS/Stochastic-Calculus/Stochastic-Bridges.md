# Stochastic Bridges

A *stochastic bridge* is a random sample path. Stochastic bridges are used to model and understand rare events.

A *random sample path*, in turn, is a sequence of random variables. Let us first start with a definition.

<i>

**definition [d]** (*Random Sample Path*) 
A *random sample path* is a sequence of random variables, $ X_1, X_2,...,X_n $ such that

1. $X_1, X_2, ..., X_n$ are independent \quad and
2. $X_1, X_2, ..., X_n$ have identical distributions

</i>

When random variables are independent and have identical distributions, we use the abbreviation *i.i.d*.
