# Stochastic Process

<i>

**definition [d]** (*Stochastic Process*) 
A *stochastic process* is a set of random variables, $\{X(t)\, t \in I\}$ defined on a probability space $(\Omega, \mathcal{F}, \mathbb{P})$, where

1. $t$ is the time variable in I
2. $I$ is a real interval that is open, closed, or half-closed
