# Statistical Learning

More commonly known as machine learning, statistical learning is the set of formulas, including algorithms, for finding that which relates some dimensions of data given the other dimensions.

<!--
Function estimation. Statistical learning uses observed data to estimate an unknown relationship between input variables and an output variable. This principle is used to predict unseen outcomes and understand how measured variables influence a response.

Supervised learning. Supervised learning estimates relationships from observations containing both inputs and known outputs. This principle is used to solve prediction and classification problems when labeled examples are available.

Unsupervised learning. Unsupervised learning analyzes observations without designated output labels to identify structure within the data. This principle is used to discover clusters, lower-dimensional representations, and systematic patterns in complex datasets.

Prediction and inference. Prediction seeks accurate outcomes for unseen observations, while inference seeks understanding of relationships between variables. This principle is used to choose learning methods according to the primary objective: predictive accuracy, scientific interpretation.

Bias-variance tradeoff. Prediction error reflects a balance between systematic error from restrictive models and sensitivity to variation in training data. This principle is used to select model complexity that minimizes expected prediction error on unseen data.

Overfitting. Overfitting occurs when a model captures accidental variation in the training data rather than patterns that generalize to new observations. This principle is used to explain why increasing model complexity can improve training performance while degrading predictive performance.

Training and test error. Training error measures performance on data used for fitting, while test error measures performance on unseen data. This principle is used to evaluate generalization and select models according to expected performance beyond the training sample.

## Problems

- Estimate $f$ in $Y=f(X)+\epsilon$ from an independent sample of pairs $(X,Y)$.
- Decompose $E[(Y-\hat f(X))^2]$ into reducible error and $\mathrm{Var}(\epsilon)$.
- Decompose expected test mean squared error into squared bias, variance, and irreducible error.
- Distinguish a regression problem from a classification problem by the type of $Y$.
- Minimize expected prediction error on a test pair independent of the training sample.
- Identify overfitting as small training error together with large test error.
