# Field

A field describes how the influence of an object is distributed through space.

Note: Also called a field. Examples include scalar fields, vector fields, and tensor fields.

<i>

**definition [d]** (*Field*) From Susskind and Cabannes: such a function, which to each point of a space associates a thing (a scalar, a vector, a tensor, etc.), is called a field (respectively a scalar field, a vector field, and tensor field, etc.).

where

- a scalar field assigns a number to each point.
- a vector field assigns a vector to each point.
- a tensor field assigns a tensor to each point.

</i>

<i>

**definition [d]** (*Field*) From Griffiths: in physics, the word field denotes generically any function of position $(x, y, z)$ and time $(t)$. But in electrodynamics, two particular fields ($\mathbf{E}$ and $\mathbf{B}$) are of such paramount importance as to preempt the term. Thus, technically, the potentials are also “fields,” but we never call them that.

where

- a field is a function of position and time.
- $\mathbf{E}$ and $\mathbf{B}$ are the electric and magnetic fields.

</i>

<i>

**definition [d]** (*Field*) From Knight: the term “field,” which comes from mathematics, describes a function that assigns a vector to every point in space.

where

- the assigned value at each point is a vector.

</i>

## Elementary Example

### Simple

A constant vector field on the plane assigns the same vector at every point:

$$
\mathbf{F}(x, y) = (1, 0)
$$

where

- every point gets the vector $(1, 0)$.

### General

A radial vector field on three sample points assigns

$$
\mathbf{F}(1, 0, 0) = (1, 0, 0),\quad
\mathbf{F}(0, 1, 0) = (0, 1, 0),\quad
\mathbf{F}(0, 0, 1) = (0, 0, 1)
$$

where

- each point gets a vector along its position direction.
