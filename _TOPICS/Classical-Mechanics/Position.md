# Position

A location of an object relative to a chosen coordinate system that is used to say where the object is in space.

Note: Also described by a position vector. Also called the radius vector from a reference point.

1. Locates an object with respect to a chosen coordinate system.
2. Can be written as coordinates $(x, y, z)$ of a point in space.
3. Can be written as a position vector from a fixed origin to that point.
4. Changes when the object moves, tracing a path through space.
5. Depends on the choice of origin and axes of the coordinate system.
6. Serves as the starting variable for velocity and acceleration.
