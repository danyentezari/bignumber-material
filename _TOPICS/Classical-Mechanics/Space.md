# Space

A three-dimensional Euclidean set that is used to locate where objects and events sit in classical physics.


1. Is the setting in which every classical motion takes place.
2. Has three dimensions, unlike spacetime which also includes time.
3. Treats time as a separate variable rather than a geometric coordinate.
4. Is the space in which ordinary positions, paths, and displacements are measured.
5. Is modeled as Euclidean, so shortest distances obey the usual Pythagorean rule.
6. Remains the spatial stage of classical physics when relativity is not required.
