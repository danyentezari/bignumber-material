# Time

An absolute parameter that is used to order events and mark how long motion lasts in classical physics.

Note: Also called absolute time. Also called Newtonian time.

1. Is treated as absolute and independent of any reference frame.
2. Is the same for all observers in Newtonian mechanics.
3. Is measured the same by all experimenters independent of their motion.
4. Runs as a single shared clock for every classical frame.
5. Enters classical laws as the independent variable of motion.
6. Is kept separate from the three dimensions of space.
