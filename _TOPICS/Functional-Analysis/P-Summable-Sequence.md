# P-Summable Sequence

A sequence whose absolute values raised to a parameter power form a convergent series. Used as an element of that set when measuring size by the matching norm.

<i>

**definition [d]** (*p-Summable Sequence*) A sequence $x = (\xi_{j})$ belonging to the set $\ell^{p}$:

- $x \in \ell^{p} = \left\{ (\xi_{j})_{j=1}^{\infty} \;\middle|\; \displaystyle\sum_{j=1}^{\infty} |\xi_{j}|^{p} < \infty \right\}$ ,

for fixed $p \geq 1$.

where

- $x = (\xi_{j})$ is the sequence.
- $\ell^{p}$ is the space of $p$-summable sequences.
- $p \geq 1$ is a fixed real number.

Note:

- equivalently, $\sum_{j}|\xi_{j}|^{p}$ converges.

</i>

<i>

**definition [d]** (*p-Summable Sequence*) An element of the set $\ell^{p}$ of sequences with finite $p$-norm:

- $\ell^{p} = \left\{ x = \{x_{j}\}_{j=1}^{\infty} \;\middle|\; \lVert x \rVert_{p} = \left( \sum_{j=1}^{\infty} |x_{j}|^{p} \right)^{\dfrac{1}{p}} < \infty \right\}$ ,

for $1 \leq p < \infty$.

where

- $x = \{x_{j}\}$ is the sequence.
- $\lVert x \rVert_{p}$ is the $p$-norm.
- $\ell^{p}$ is the set of all such sequences.

Note:

- Gamelin and Greene’s index lists “p-summable sequences” for this notion.
- the scalars may be real.
- the scalars may be complex.

</i>
