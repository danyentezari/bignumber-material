# Ell P

<i>

**definition [d]** (*$\ell^{p}$ = $\ell^{p}$ Space*) The set of all sequences $x = (\xi_{j})$ of scalars for which the series of $p$-th powers converges:

- $\ell^{p} = \left\{ x = (\xi_{j})_{j=1}^{\infty} \;\middle|\; \displaystyle\sum_{j=1}^{\infty} |\xi_{j}|^{p} < \infty \right\}$ ,

for a fixed real number $p \geq 1$.

where

- $\ell^{p}$ is the sequence space.
- $x = (\xi_{j})$ is a sequence of scalars.
- $p \geq 1$ is a fixed real number.

Note:

- equipped with $\lVert x \rVert_{p} = \bigl(\sum_{j}|\xi_{j}|^{p}\bigr)^{\dfrac{1}{p}}$, the set $\ell^{p}$ is a Banach space.
- the case $p = 2$ is the Hilbert sequence space $\ell^{2}$.

</i>

<i>

**definition [d]** (*$\ell^{p}$ = $\ell^{p}$ Space*) The set of all sequences of scalars with finite $p$-norm:

- $\ell^{p} = \left\{ x = \{x_{j}\}_{j=1}^{\infty} \;\middle|\; \lVert x \rVert_{p} = \left( \displaystyle\sum_{j=1}^{\infty} |x_{j}|^{p} \right)^{\dfrac{1}{p}} < \infty \right\}$ ,

for $1 \leq p < \infty$.

where

- $\ell^{p}$ is the sequence space.
- $x = \{x_{j}\}$ is a sequence of scalars.
- $\lVert x \rVert_{p}$ is the $p$-norm of $x$.
- $p$ is a real number with $1 \leq p < \infty$.

Note:

- the scalars may be real.
- the scalars may be complex.
- Gamelin and Greene identify the elements of $\ell^{p}$ as p-summable sequences.

</i>
