# Open Set

An open set is a member of a topology on a set, used to define neighborhoods and continuity of mappings.

<i>

**Definition** (_Open Set_) A subset $U$ of a topological space, $(X,\mathcal{T})$, where the following condition applies:

- $U \in \mathcal{T}$

where

- $X$ is a set
- $\mathcal{T}$ is a topology on $X$
- $U \subseteq X$

</i>
